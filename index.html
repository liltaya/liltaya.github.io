Developer tool · Solo · Oct to Nov 2026

BuildScope

BuildScope runs CI pipelines on your own machine and keeps every attempt, test result and benchmark sample. From that history it answers the questions CI dashboards leave to you: which commit broke the build, which tests are flaky rather than broken, and which stage got slower and by how much.

Materials
Python, FastAPI, SQLAlchemy, SQLite, JavaScript, C++20
Inside
DAG validation, a durable job queue with leases and crash recovery, flaky-test classification, benchmark slowdown detection, a logistic-regression failure model
Dimensions
24 merged pull requests · 706 test cases · CI on Ubuntu and macOS · v0.1.0

Tested 13 Nov 2026
pytest · 706 passed, 15 skipped
1 min 49 s on Linux, Python 3.12

Game · Team of four · ENSC 251 · Fall 2026

Virus.exe

A two-player strategy card game for Software Design and Analysis for Engineers. Each player defends a computer made of four parts, CPU, memory, network and storage, and each suit of an ordinary 52-card deck targets one of them. Number cards deal damage, face cards make repairs and an ace raises a shield for one turn. Take down all four of the other player's parts to win; if the cards run out, the computer with the most health left wins.

Materials
C++, object-oriented design
My part
Proposed the concept and rules, designed the class model, and wrote the Game class (turns, card effects, win check) and the GameUI text interface
Status
In progress; the team is joining the classes into one build this term
