Construction Analytics Dashboard

A Qt6 desktop app that turns raw construction project data into four views, so a manager can spot budget overruns and overdue work at a glance.

  • Project selector, live search, category and status filters, sortable tables, and a custom QPainter chart with hand-written drawing, scaling and layout math instead of a charting library.
  • CSV import checks headers, field counts, IDs, statuses and budgets, reports errors by row number, and wraps each import in an all-or-nothing SQLite transaction.
  • Layered design: UI, service, analytics, repository, and RAII-managed SQLite. Architecture and data model are documented.

Operational Data Platform and Log Analyzer

A REST API deployed the way production services are, with health checks and live metrics, plus a command-line tool that reads server logs and flags trouble.

  • Flask, SQLAlchemy and PostgreSQL API with input validation, structured JSON errors, health checks, and Prometheus metrics feeding Grafana dashboards.

  • Log analyzer built with dataclasses and type hints. Reports error rates, malformed lines and suspicious requests (path traversal, SQL injection, scanners) as text, JSON or CSV.
